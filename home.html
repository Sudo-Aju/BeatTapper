ABOUT.TXT

BeatTapper is a responsive rhythm game featuring four-lane gameplay. Hit falling notes in sync with the beat using keys A S D F.

UI and theme inspired by WIN95 — clean playfield, dynamic hold notes, and a combo + judgement scoring system. Optimized for smooth animation and precise input feedback.

FEATURES.EXE
  • Responsive four-lane canvas
  • PERFECT / GREAT / GOOD / MISS judgement
  • Real-time lane flash & hit feedback
  • Combo counter + score tracking
  • Vanilla JS — zero dependencies
  • requestAnimationFrame 60 FPS loop
  • Modular beatmap/note generation
  • Custom map support 🤓
HOW_TO_PLAY.TXT
  1. Open the Play link in the About section of this repo.
  2. Wait for the game to begin — no install needed.
  3. Press the correct key when a note crosses the hit line.
  4. Hold A/S/D/F for sustained hold notes until complete.
  5. Score points for timing accuracy. Keep that combo alive.
